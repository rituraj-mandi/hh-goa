# 🌴 HH Goa 2026 — Builder Card Generator

A simple web app to create your personalized **Hacker House Goa 2026 Builder Card**.

### ✨ Features

* Upload your photo
* Add your name & role
* Generate random builder titles
* Preview your card instantly
* Download as PNG
* Share directly to X

### 🛠️ Built With

**HTML • CSS • JavaScript • Canvas API**

### 🚀 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/hh-goa-id-generator.git

```

Open `index.html` in your browser, or use **Live Server**.
